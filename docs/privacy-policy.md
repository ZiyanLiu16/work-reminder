# Privacy Policy for 回到目标 · Work Reminder

Effective date: September 23, 2026

回到目标 · Work Reminder helps users track time spent on websites they choose and displays reminders based on goals and content saved by the user.

## Data handled by the extension

The extension handles the following information on the user's device:

- The domain or URL of the active tab, solely to determine whether it matches the user's reminder-site list.
- Browser foreground state, page visibility, device idle state, elapsed browsing time, and whether a visible page contains a normally playing video.
- Goals, reminder intervals, website domains, encouragement links and excerpts entered by the user.
- Text snippets that the user explicitly selects from local project folders.

## How data is used

This information is used only to calculate browsing time and display the reminder features described in the extension and its Chrome Web Store listing.

## Storage and transfer

All settings and selected content are stored locally in `chrome.storage.local`. Temporary timer state is stored in `chrome.storage.session`. The extension has no developer-operated server and does not transmit user data to the developer or third parties.

The extension does not sell user data, use it for advertising, use it to determine creditworthiness, or allow humans to read it.

## Website access

The extension includes access to its default supported websites. When a user adds another website, Chrome displays a permission request for the domain entered by the user. The extension uses that access only to measure eligible foreground browsing and display its reminder interface. It does not read page text, form entries, cookies, account information, or network request contents.

## Local project folders

Project-folder access begins only after the user selects a folder in the extension settings. The extension filters files, presents candidate text snippets for review, and saves only snippets explicitly selected by the user. It does not execute project files or upload them. Users should exclude any snippet they do not want stored by the extension.

## Data retention and deletion

Data remains in the user's local Chrome profile until the user removes it. Users can delete all extension data from the settings page or by uninstalling the extension.

## Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single purpose and user-facing features.

## Changes

If the extension's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed practices are released.
