# Chrome Web Store listing

## Product name

回到目标 · Work Reminder

## Summary

浏览一会儿，记得回来。达到自定时间后，用你的目标、项目片段或鼓励内容提醒你把注意力带回来。

## Detailed description

回到目标是一款在本机运行的注意力提醒扩展。你可以选择容易消耗时间的网站，并设置累计浏览多久后出现提醒。达到时间后，扩展会从你的个人目标、项目片段和鼓励内容中选择一种，以不打断当前页面操作的方式提醒你。

主要功能：

• 自定义需要提醒的网站和提醒间隔
• 只在 Chrome 位于前台、目标标签页可见时累计时间
• 系统闲置或锁屏时自动暂停
• 暂时将当前标签页设为 60 分钟学习模式
• 选择本地项目目录并保存少量文本片段，让提醒指向正在推进的工作
• 保存鼓励内容的链接、摘录和作者
• 在设置页随时暂停提醒或清除全部数据

隐私设计：

目标、项目片段、网站列表、鼓励内容和计时状态都保存在你的设备上。扩展没有开发者服务器，不发送分析数据，也不向第三方出售或分享数据。

扩展默认支持 YouTube、哔哩哔哩和小红书。你可以删除这些网站，也可以在主动授权后添加其他 HTTP 或 HTTPS 网站。
